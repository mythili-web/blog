What I Learned from My First Web Project

Creating my first website taught me a lot about layout, CSS styling, and browser compatibility. It also helped me understand how important clean structure and readable code are.

Why Soft Skills Matter

Good communication and teamwork helped me a lot during college projects. Expressing ideas clearly and working well with others made every team project smoother and more enjoyable.
